+
+GET
+
+`/v1/origin/search/pulls`
+
+Requires scopes `repository:pull_requests:read`, `repository:pull_requests:reviews:read` (user access token).
+
+Searches pull requests in one namespace, an org or a user, with a pull request search query. It searches the repositories the query names with `repo:`, `org:`, or `user:`, or the `repo` repository when the query names none, and returns the same pull request items as [List Pull Requests](https://cursor.com/docs/api/origin/llms-full.txt#list-pull-requests). +
+A query whose `repo:`, `org:`, and `user:` qualifiers name more than one namespace, or one that names none when `repo` isn't set, returns `InvalidArgument` (HTTP 400) with a field violation on `q`. Add `org:NAME` to search one namespace.
+
+Search matches review state as well as pull request fields, so the caller needs both `repository:pull_requests:read` and `repository:pull_requests:reviews:read`, and search covers only repositories that grant both. +
+Searching with `org:` or `user:` needs a user credential that isn't limited to specific repositories, or a service account. +
