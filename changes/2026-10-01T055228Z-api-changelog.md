 Origin API Changelog
 The Origin API is in Early Beta and subject to change. Review the OpenAPI specification when updating an integration.
 Changes to the Origin public API, including endpoints, request and response schemas, scopes, and webhooks, grouped by day with the newest first. Each change carries one label: Breaking, Deprecated, Added, Changed, or Removed. Breaking and deprecated changes include migration guidance inline. The Origin API reference always reflects the latest synced state.
+September 30, 2026
+Breaking. Create Ruleset and Update Ruleset reject a rule whose ruleType never runs in the ruleset's kind with InvalidArgument (HTTP 400), where Origin used to store the rule and never run it. A merge_branch ruleset accepts only the merge rule types pull_request, require_status_checks, and require_branch_up_to_date, and a push_branch, push_tag, or push_repository ruleset accepts only push-time rule types, such as deletion and non_fast_forward. An update that sends back a mismatched rule the ruleset already stores fails the same way. Migration: move each rule into a ruleset of the kind it runs in before you call Create Ruleset or Update Ruleset.
+Breaking. Transition Repo Mirror returns FailedPrecondition (HTTP 400) for an inbound_to_outbound transition unless outbound mirroring is enabled for the repository. The reference and the OpenAPI specification no longer describe outbound mirroring: Force Repo Mirror Cutover and the inbound_to_outbound and outbound_to_inbound transitions, announced on September 11, were removed, as was the outbound value of mirror.status. Repositories already mirroring outbound keep working. Migration: keep mirrored repositories inbound, and send Transition Repo Mirror only initial_to_inbound, which retries a mirror whose initial sync failed.
+Added. Get Repository Collaborator Permission returns a user's permission on a repository, combined from their direct and inherited grants: GET /v1/origin/repos/{ownerSlug}/{repoName}/collaborators/{userId}/permission. The response carries the user and a permission of read, write, admin, or custom, which can differ from the permission of any single grant. A user whose grants give no access, an ID that names no active account, a mirrored repository, and a repository you can't see all return 404. Requires repository:metadata:read and costs 1 point.
+Added. Post Check Run and Batch Upsert Check Runs accept an optional baseSha naming the base a check run was evaluated against: a pull request version's baseSha, as a 40- or 64-character hex SHA. It is part of the check suite and check run identity, so the same externalId and key posted against another base creates a separate attempt instead of overwriting the first, and a later post must repeat the value to address the same attempt. An empty string returns InvalidArgument (HTTP 400); omit the field for a base-agnostic run.
+Added. Check suite and check run responses carry baseSha, in lowercase, when the reporting app supplied one, and omit it for a base-agnostic attempt. Returned by Post Check Run, Batch Upsert Check Runs, Get Check Run, Rerequest Check Run, Get Check Suite, List Check Runs For Suite, List Check Runs For Commit, and List Check Suites For Commit, and carried by the check run payloads, the check run rerequested payload, and the check run annotations payload.
+Changed. Every team namespace can use and enforce an inbound IP allowlist, superseding the September 29 note that allowlists are available only on team namespaces with the feature enabled. The allowlist endpoints still return FailedPrecondition (HTTP 400) for a namespace that no team owns.
+Changed. A namespace's inbound IP allowlist holds up to 1,000 entries, up from the 100 announced on September 29. Get Inbound IP Allowlist returns at most 1,000 entries, and Add Inbound IP Allowlist Entry returns InvalidArgument (HTTP 400) once the list already holds 1,000.
+Changed. Create Commit From Files drops <, >, and newline characters from the name and email of author and committer, as git commit does, where a value containing them used to fail the request with an internal error (HTTP 500). A name or email made only of those characters returns InvalidArgument (HTTP 400).
 September 29, 2026
 Pull requests
 Breaking. Update Pull Request no longer reopens a pull request whose head branch was deleted. Setting state to "open" or draft to false on such a closed pull request returns FailedPrecondition (HTTP 400) and leaves it closed, where Origin used to reopen it with no head to read. Migration: push the head branch again before you reopen the pull request.
