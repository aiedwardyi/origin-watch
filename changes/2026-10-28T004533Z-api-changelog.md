 Origin API Changelog
 The Origin API is in Early Beta and subject to change. Review the OpenAPI specification when updating an integration.
 Changes to the Origin public API, including endpoints, request and response schemas, scopes, and webhooks, grouped by day with the newest first. Each change carries one label: Breaking, Deprecated, Added, Changed, or Removed. Breaking and deprecated changes include migration guidance inline. The Origin API reference always reflects the latest synced state.
+October 27, 2026
+Breaking. Enable Pull Request Auto Merge returns PermissionDenied (HTTP 403) to a service account, as it already did to an installation user token, because auto-merge merges later as the principal that turned it on and Origin can't act as a service account then. These requests used to succeed and left auto-merge on without ever merging. Auto-merge that a service account turned on before this change is turned off, and pull_request.merge_when_ready.disabled reports enabler_lost_access as its disabledReason. Migration: merge the pull request with Merge Pull Request once it's mergeable, or have a person turn on auto-merge with their Cursor user credential.
+Breaking. Enable Pull Request Auto Merge rejects mergeMethod merge with FailedPrecondition (HTTP 400) when an active required_linear_history rule covers the pull request's base branch and squash merges are allowed there, because auto-merge lands without a ruleset bypass and the rule refuses its merge commit. These requests used to succeed. Auto-merge already on with merge for such a branch is turned off, and pull_request.merge_when_ready.disabled reports merge_failed as its disabledReason. Migration: send squash, or omit mergeMethod to land the default, when the base branch requires linear history.
 October 25, 2026
 Breaking. Post Check Run and Batch Upsert Check Runs return InvalidArgument (HTTP 400) for a check suite or check run whose name is longer than 255 characters or whose detailsUrl is longer than 8,192 characters, where these requests used to succeed. A batch with one such run writes none of its runs. Migration: truncate name to 255 characters and detailsUrl to 8,192 characters on checkSuite, checkRun, and each checkRuns[] entry before you post.
