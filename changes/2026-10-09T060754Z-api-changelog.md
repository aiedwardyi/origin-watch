 Origin API Changelog
 The Origin API is in Early Beta and subject to change. Review the OpenAPI specification when updating an integration.
 Changes to the Origin public API, including endpoints, request and response schemas, scopes, and webhooks, grouped by day with the newest first. Each change carries one label: Breaking, Deprecated, Added, Changed, or Removed. Breaking and deprecated changes include migration guidance inline. The Origin API reference always reflects the latest synced state.
+October 8, 2026
+Breaking. Merge Pull Request returns FailedPrecondition (HTTP 400), and nothing merges, when the pull request's base branch is the head branch of another open or draft pull request that it isn't stacked on. For a stack, the base that counts is the one the merge lands on. Such a merge used to land on the other pull request's branch. The repository's default branch is exempt, as is a base branch that an active push_branch ruleset with a deletion rule names in includedRefNames. Get Pull Request Mergeability reports the condition as a needs_restack blocker. Migration: merge the pull request that owns the base branch first, or stack this pull request on it by setting parentPullRequest with Update Pull Request.
+Added. List Pull Requests accepts labels, repeated once per label name, and returns only pull requests that carry every named label. A comma is part of a name, so labels=bug,security names one label. More than 10 names, a name longer than 50 characters, or a name that isn't a label in the repository returns an empty list. The parameter is in preview.
 October 6, 2026
 Breaking. A user actor's email is an empty string in pull request, review, comment, check run, requested reviewer, and merge eligibility responses, such as author.user.email on Get Pull Request, unless the caller holds repository:members:read on the repository. List Pull Requests rejects an email author filter from such a caller with PermissionDenied (HTTP 403). Webhook payloads still carry emails. Installations that held repository:metadata:read when Origin split out repository:members:read on October 3 already hold it. Migration: request repository:members:read to read user emails and filter by author email, or filter List Pull Requests by the author's user_… ID.
 Breaking. Get Repo returns mirror only to a caller holding repository:mirror:read on the repository and omits it otherwise, as it does for a native repository. Installations and apps' default scopes don't include that scope, so an installation reads mirror from Get Repo only after a workspace admin approves repository:mirror:read for it. Migration: request repository:mirror:read to keep reading mirror from Get Repo.
