+### Enable Pull Request Auto Merge
+
+PUT
+
+`/v1/origin/repos/{ownerSlug}/{repoName}/pulls/{pullNumber}/auto_merge`
+
+Requires scope `repository:contents:write` (installation access token or user access token).
+
+Enables auto-merge on a pull request: Origin merges it on your behalf once it's mergeable, and a stacked pull request only once it's also the lowest open pull request in its stack.
+
+The body can choose the merge method and the merge commit's title and message. An empty body lands with the default merge method and a commit message Origin composes. The response is the pull request with `autoMerge` set. Calling it while auto-merge is already on re-arms it for the caller with this call's options.
+
+A closed or merged pull request returns `FailedPrecondition` (HTTP 400). A draft pull request can be armed, and it merges only once it's ready for review. Retargeting the pull request with [Update Pull Request](https://cursor.com/docs/api/origin/llms-full.txt#update-pull-request) keeps auto-merge on, and the merge lands on the base branch the pull request has then. Installation user tokens can't enable auto-merge: the request returns `PermissionDenied` (HTTP 403).
+
+Turn auto-merge off with [Disable Pull Request Auto Merge](https://cursor.com/docs/api/origin/llms-full.txt#disable-pull-request-auto-merge). Turning it on and off sends the [`pull_request.merge_when_ready.enabled`](https://cursor.com/docs/api/origin/llms-full.txt#events) and `pull_request.merge_when_ready.disabled` webhook events, and a merge it lands sends `pull_request.merged`.
+
+This operation is in [preview](https://cursor.com/docs/api/origin/llms-full.txt#preview), and its shape can change while the contract settles.
